같은 값, 다른 바이트 — 텍스트 vs 바이너리

25.3 을 fprintf 로 쓰면 글자 4개, fwrite 로 쓰면 double 8바이트. 구조체 하나는 16바이트.

텍스트 — fprintf(fp, "%.1f,%d,%d\n", t, h, d)
바이너리 — fwrite(&r, sizeof r, 1, fp) (double 8 · int 4 · int 4, 리틀 엔디안)
텍스트 크기
바이너리 크기16 bytes
텍스트로 읽으려면strtod / strtol 파싱
바이너리로 읽으려면fread 한 번
텍스트는 사람과 Excel 이 읽고, 바이너리는 정확하고 빠릅니다. 단, 바이너리는 같은 컴파일러·같은 CPU 에서만 (패딩·엔디안).
