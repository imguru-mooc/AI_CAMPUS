## 트러블슈팅

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| `Makefile:9: *** missing separator` | 명령 줄이 스페이스로 시작 | 에디터에서 탭 입력 확인 (`cat -A Makefile`로 `^I` 확인) |
| `./run.sh: Permission denied` | 실행 권한 없음 | `chmod +x run.sh` |
| `/bin/bash^M: bad interpreter` | Windows 줄바꿈(CRLF) | `sed -i 's/\r$//' run.sh` 또는 `dos2unix` |
| `strace: command not found` | 패키지 미설치 | `sudo apt install strace` |
| `strace: attach: ptrace … Operation not permitted` | 이미 실행 중인 프로세스에 `-p`로 붙음 | 처음부터 `strace ./prog`로 실행하거나 `sudo` |
| `/etc/shadow`가 성공으로 나옴 | sudo나 root로 실행 | 일반 사용자로 다시 실행 |
| 좀비가 ps에 안 보임 | 20초 지남, 또는 `$!`가 다른 PID | `./07_zombie &` 직후 바로 ps 실행 |
| 고아의 PPID가 1이 아님 | `systemd --user`가 subreaper | 정상. `ps -p <PPID> -o cmd`로 확인시키기 |
| myshell에서 Ctrl+C 시 셸까지 종료 | `signal(SIGINT, SIG_IGN)` 누락 | 루프 진입 전 호출 확인 |
| myshell에서 `sleep` Ctrl+C가 안 먹음 | 자식에서 `SIG_DFL` 복원 누락 | fork 후 자식 쪽에 `signal(SIGINT, SIG_DFL)` |
| 코어 수 1 (VM) | vCPU 1개 할당 | VM 종료 후 설정에서 2개 이상 — Day 2 전까지 필수 |
