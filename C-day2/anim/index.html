포인터는 화살표다

p 에 주소를 넣으면 화살표가 생깁니다. 화살표를 따라가 값을 읽고 쓰는 것이 *p 입니다.

0x7ffc..20
5
int x
0x7ffc..24
9
int y
0x7ffc..28
?
int *p
// p 는 아직 아무 곳도 가리키지 않습니다 (쓰레기 값)

p + 1 은 몇 바이트 이동하는가

같은 메모리라도 포인터의 타입에 따라 +1 의 보폭이 다릅니다.

메모리 (주소 0x1000 부터 32바이트)
p0x1000
p + n
이동한 바이트
(p + n) − p

왼쪽은 수정 가능한 복사본, 오른쪽은 읽기 전용 리터럴. 아래는 8칸 버퍼에 긴 문자열을 복사하는 실험.

스택 — char s1[] = "ABC"
sizeof = 4 · strlen = 3

strtok 은 원본을 자른다

구분자 자리에 '\0' 을 써 넣고 그 앞 조각의 시작 주소를 돌려줍니다.

char line[] = "$T=25.3,H=60,D=120*" (strtok(line + 1, ",") 부터)
문자열 리터럴(char *s = "…")에 strtok 을 쓰면 읽기 전용 메모리에 '\0' 을 쓰려다 세그폴트. 반드시 배열(복사본)에 쓰세요.
