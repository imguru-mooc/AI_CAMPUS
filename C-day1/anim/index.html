    fact(3)이 호출될 때 스택에서 벌어지는 일
    
      
    한 단계씩 진행하며 프레임이 쌓이고 사라지는 것을 보세요. static 변수는 스택 밖에 삽니다.
    
    
    
    
    
      
    
        
        
        시작하려면 다음 단계를 누르세요.
      
    
      
    
        
    static int calls = 0;
int fact(int n) {
    calls++;
    if (n <= 1) return 1;
    return n * fact(n - 1);
}
int main(void) {
    int r = fact(3);
}
