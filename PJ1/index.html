사용 방법

  1. 아래에서 오늘 일차의 산출물을 열고 양식 Markdown 복사를 누릅니다.
  2. 조 GitHub 저장소의 docs/ 폴더에 안내된 파일명으로 붙여 넣고 작성합니다. Notion에 붙여 넣어도 표가 그대로 만들어집니다.
  3. 작성이 막히면 작성 예시 탭을 참고합니다. 예시의 수치는 모두 가상 값입니다.
  4. 매일 8교시에 push합니다. 이미지 데이터와 개인 평가서는 저장소에 올리지 않습니다.
