systemd 서비스 파일

작성 안내: 조에서 등록한 서비스 파일 내용을 붙여 넣습니다. 모니터 화면 표시가 필요하면 데스크톱 로그인 이후에 실행되도록 설정해야 합니다.

[Unit]
Description=
After=multi-user.target

[Service]
User=
WorkingDirectory=
ExecStart=
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target

통합 점검

  • 모든 모듈이 main.py 하나로 실행됨
  • 임계값·핀 번호·구역 좌표가 설정 파일에 있음
  • systemctl enable로 등록함
  • 전원을 껐다 켜면 자동으로 실행됨
  • 프로그램을 강제 종료하면 자동으로 다시 시작됨
  • 종료 시 GPIO 출력이 모두 꺼짐

systemd 서비스 파일

[Unit]
Description=SafeCam safety monitor
After=multi-user.target

[Service]
User=pi
WorkingDirectory=/home/pi/safecam
ExecStart=/home/pi/safecam/.venv/bin/python main.py --config config.yaml
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target

  • ✓모든 모듈이 main.py 하나로 실행됨
