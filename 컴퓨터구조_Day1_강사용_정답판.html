실습 2 — 부품 이름표

공개 시점: S2-9 · 학생 화면의 「정답 확인」 버튼과 동일 기준
자리위치 설명정답
①메인보드 가운데, 방열판 아래CPU
②① 바로 옆 슬롯, 길쭉한 막대메모리(RAM)
③구석의 상자 또는 별도 슬롯의 막대저장장치(SSD/HDD)
④본체 바깥 (키보드·마우스·모니터 자리)입출력장치
최다 오답: ②↔③ 바꿔 고르기 (둘 다 막대) → "위치가 가릅니다 — CPU 옆이냐, 구석이냐."
진행: 학생들이 각자 「정답 확인」 클릭 → ✗ 칸 수정 → 재확인. 이후 확인 문구:
"고친 칸 — ① 없다 ② 있다 ③ 모르겠다 — 번호로"

실습 3 — 부품과 역할 짝짓기

공개 시점: S3-9 · 핵심 — 잇지 않는 판단도 정답
역할 보기정답
전원을 꺼도 파일이 남는다잇지 않음 → 오후 S4 (저장장치)
지금 쓰는 것을 올려둔다메모리(RAM)
계산과 명령을 처리한다CPU
컴퓨터로 들어가고 나오는 문이 된다잇지 않음 → 오후 S4 (입출력장치)
별명정답 (포함 판정)
CPU = 일하는 ____손
메모리 = ____작업대
보너스 예시 답: "손과 작업대가 가까워야 일이 빠르기 때문 (왕복 시간)"
최다 오답: '꺼도 파일이 남는다'를 메모리에 잇기 → "작업대 위의 것은 끄면 어떻게 된다고 했죠? 이 설명의 주인은 따로 있습니다 — 오후에 만납니다."
정답 공개 후 남은 보기 2개를 가리키며: "이 두 설명의 주인은 점심 먹고 옵니다 — 누구일지 생각해 두세요." (S4 예고)
"고친 짝 — ① 없다 ② 있다 ③ 모르겠다 — 번호로"

실습 4 — 사라진다 vs 남는다

공개 시점: S4-9 · 판단 기준 한 문장 — "작업대 위인가, 창고 안인가"
🗂️ 꺼지면 사라진다 (작업대)🏬 꺼도 남는다 (창고)
작업 중이던 문서 (저장 안 함)
지금 틀어 놓은 음악의 재생 위치
열려 있는 브라우저 탭들
게임 실행 중 화면		 어제 저장한 사진 파일
다운로드해 둔 설치 파일
저장해 둔 문서 파일
저장한 게임 세이브 파일
최다 오답: '작업 중 문서'와 '저장한 문서'를 같은 칸에 → "같은 문서라도 어디에 있느냐가 운명을 가릅니다 — 전원 실험에서 본 그대로."
"고친 칸 — ① 없다 ② 있다 ③ 모르겠다 — 번호로"

실습 5 — 데이터의 길

공개 시점: S5-9 · 방향까지 맞아야 정답
🏬 저장장치 → 🗂️ 메모리 → 🧠 CPU → 🖥️ 화면
이야기로: "창고에서 꺼내 → 작업대에 올리고 → 손이 일해서 → 문으로 나간다"
최다 오답: 방향 반대 (화면→CPU 등) → "화살표가 헷갈리면 이야기 순서로 바꿔 보세요 — 이야기 순서가 곧 화살표 방향입니다."
"고친 화살표 — ① 없다 ② 있다 ③ 모르겠다 — 번호로"

실습 6 — 사양표 해석

공개 시점: S6-9 · 자유 서술이라 뜻이 같으면 정답 — 아래는 판정 기준
줄참고 답안 (비유 포함 시 정답)
프로세서 3.2GHz · 8코어손이 일하는 속도 3.2GHz · 일하는 손 8개
메모리 16GB작업대의 넓이 — 동시에 올려둘 수 있는 양
저장장치 512GB SSD창고의 크기 512GB · SSD = 빠른 창고
디스플레이 15.6인치문(모니터)의 크기 — 부품 성능 아님
필수 확인: 메모리 GB와 저장 GB를 바꿔 해석한 학생 → 기준 재정리: "그 숫자가 작업대 줄에 있나, 창고 줄에 있나."
"고친 항목 — ① 없다 ② 있다 ③ 모르겠다 — 번호로"

실습 7·8 — 캡처 · 내 사양표

정답이 없는 실습 — 통과 기준으로 확인

실습 7 통과 기준

노션의 본인 이름 아래에 시스템 정보 캡처 1장이 올라와 있다 (CPU·RAM·저장장치 항목이 화면에 보임)
"① 스크린샷 찍었다 ② 안 된다 ③ 모르겠다 — 번호로"

실습 8 통과 기준

숫자 4개(GHz · 코어 · RAM GB · 저장 GB)가 모두 채워짐 — 화면에 보이는 숫자 그대로면 정답 (표기 차이는 오답 아님)
워크시트가 자동 점검하는 것: RAM ≥ 저장 GB이면 "두 GB가 바뀌지 않았나요?" 경고 후 재확인을 요구함 — 경고를 통과한 답은 인정
"① 빈칸 다 채웠다 ② 일부만 채웠다 ③ 모르겠다 — 번호로"

실습 9 — 소개서 채점 기준

전원 제출 확인이 이 시간의 유일한 통과 기준 · 문장력 지적 금지
확인기준
재료 1부품 이름 4개 (실습 2에서 자동 조립됨)
재료 2역할 — 비유(손·작업대·창고·출입구)만 있어도 통과 (실습 3에서 자동 조립됨)
재료 3내 숫자 — GHz · 코어 · RAM · 저장 (실습 8에서 자동 조립됨)
직접 작성소개 한 문장 (자유) · 보너스는 선택
제출완성 화면 캡처가 노션의 본인 이름 아래에 있음
워크시트가 재료를 자동으로 모으므로, 순회 확인은 노션 캡처 존재 여부만 보면 됩니다. 재료가 빠진 학생은 워크시트가 어느 탭이 미완인지 표시해 줍니다.
"① 제출했다 ② 안 된다 ③ 모르겠다 — 번호로"
