fork() 해부 — CPU와 Memory에서 벌어지는 일

fork()는 「프로세스 복사기」입니다. Memory의 주소 공간과 CPU의 레지스터가 통째로 복제되고, 단 하나 — fork()의 반환값만 다릅니다. 그 한 칸의 차이로 부모와 자식의 길이 갈라지는 과정을 단계별로 봅니다.

「다음 단계」로 기본 시나리오를 시작하세요 — 각 단계에서 다음에 벌어질 일을 먼저 예측!
시나리오 — 예상 결과가 함께 표시됩니다
1int x = 10;
2pid = fork(); // 여기서 둘이 된다
3if (pid == 0)
4 x = 99; // 자식의 길
5else
6 print(x); // 부모의 길

대기 중 — fork()의 안쪽이 여기에 기록됩니다
Memory 복제
Code·Data·Stack — 주소 공간 전체가 자식에게 복사됩니다. 내용은 같고, 공간은 별개.
CPU 복제
PC를 포함한 레지스터도 복사 — 그래서 둘 다 fork() 「직후」 같은 지점에서 깨어납니다.
반환값만 다름
부모의 pid = 자식의 PID, 자식의 pid = 0 — 완전한 쌍둥이를 구별하는 유일한 한 칸.
독립성
복사본이므로 이후는 남남 — 자식이 x를 바꿔도 부모의 x는 그대로.
