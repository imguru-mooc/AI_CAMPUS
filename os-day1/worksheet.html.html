운영체제 활용 Day 1 · 디지털 워크시트 — File System과 두 인터페이스

사용 안내

오늘의 규칙 — 예측 먼저, 화면은 검산. 예측 칸은 애니메이션·실제 Terminal을 열기 전에 채웁니다. 「채점하기」를 누르면 예측 칸이 잠기고 틀린 칸 옆에 바른 답이 표시됩니다 — 종이의 「정답 맞추기」와 같은 흐름입니다.

· 답은 브라우저에 자동 저장됩니다 — 창을 닫았다 열어도 유지
· 각 실습의 도구 ▶ 링크는 워크시트 옆 anim 폴더의 애니메이션을 새 창으로 엽니다
· 실습마다 「실습 완료 화면 만들기」 — 완료 화면에는 점수와 함께 내가 작성한 내용이 그대로 표시됩니다
· 실습 9(도착점)의 완료 화면에는 하루 전체 요약이 포함됩니다 — 그 화면을 인쇄/PDF로 제출
· 명령어 표기는 현재 CMD 기준(탐색 명령은 ls·pwd도 정답 처리) — Shell 확정 시 고정
· Terminal·GUI/CLI 결과 캡처 제출물은 별도 채널에 업로드 — 채널은 강사 확정
